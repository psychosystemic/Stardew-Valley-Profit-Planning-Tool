# SPP — Stardew Profit Planner

SPP is an unofficial Stardew Valley fan tool for comparing what to do with crops, forageables, animal products, recipes, artisan goods, and cask-aging options.

## What it does

SPP can compare:

- selling items raw
- Kegs, Preserves Jars, Dehydrators, Oil Makers, Looms, Cheese Presses, and Mayonnaise Machines
- cooking recipes
- quality-loss and quality-preservation rules
- multi-step processing chains
- Cask aging
- gold per machine-day
- gold per Cask-day
- profession effects
- Community Center / recipe "keep one" reminders
- whole-farm inventory optimization with limited machine counts

Fish are intentionally excluded from the decision engine.

## GitHub Pages setup

1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. Open **Settings** → **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. GitHub will provide a public Pages URL after deployment finishes.

Because SPP is a single self-contained HTML file, there are no build tools, package managers, or dependencies required.

## Updating SPP

To publish a newer version later, replace `index.html` in the repository with the updated SPP HTML file and commit the change. GitHub Pages will redeploy automatically.
